## 🎯 О проекте
**Softy** - это полнофункциональное веб-приложение для автоматизации работы салона красоты. Главная фишка проекта - интерактивная 3D-примерка татуировок прямо в браузере с использованием **Three.js**. Клиенты могут записаться на процедуры онлайн, а администраторы получают удобную панель управления расписанием и услугами.

### ✨ Ключевые возможности
- ️ **3D Примерка тату**: Наложение эскизов на выбранные зоны тела в реальном времени (Three.js).
- 📅 **Онлайн-запись**: Удобный календарь бронирования процедур и мастеров.
- 💼 **Админ-панель**: Управление услугами, мастерами, расписанием и клиентами.
- 🏠 **Информационный раздел**: Описание салона, прайс-лист.
-  **Авторизация**: Разделение ролей (Клиент / Администратор).
